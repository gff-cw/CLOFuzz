## 通用性与未扩展范围

- **R01/R02**：零长度 replay 仍拒绝；零提交尝试只作诊断。共同 bundle digest 用于成对声明一致性，运行时不据此认证任意文件内容或进程映像；manifest 的实际文件摘要也不是签名。
- **R03**：本轮未测成本、采样开销或调度收益，不能新增性能结论。
- **G01**：修正[能力矩阵](format-capability-matrix.md)中的关联键、容量和字段分类，尤其旧 YAML 的 guard/actions 及依赖 scope/when 是注释，不是自动执行或统一拒绝。
- **G02**：generic-wire 是有界平铺 uint/bytes 语言。现有六 profile 迁移器有固定选择表，不是一般 YAML 编译器。
- **G03**：六个 generic profile 仍只有 14 个迁移消息、57 个 unsupported ID；五份 offline-only，Modbus 仅 FC03 单寄存器请求及正常响应。旧专用 codec 能力与该范围分别说明。
- **G04**：模板是明确格式的配置骨架，不能自动生成新协议解析器或可靠的消息/内存边界。最小样例只是对应 codec 的完整参考输入，未在本轮执行。
