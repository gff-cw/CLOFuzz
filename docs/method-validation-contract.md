# 变异策略的方法验证契约

目标是验证变异策略接入 StateAFL 后的正确性及实验有效性。依据是可控输入、明确预期和可追溯观察；发现未知漏洞或 crash 数量不是必要条件。

`23e0f0d` 之前的修复按当时约束只做静态审查；用户后续授权编译，默认64位主工具和 LLVM 组件已实际构建，并修复了编译阻断。**编译通过仍不能宣称运行正确性或方法有效。** 编译结果和进一步反思见[编译复核](build-review-20261103.md)，原逐项清单见[修复记录](repair-status-20261102.md)，历史基线见[静态复核](../ONLINE_DIRECTED_MUTATION_RECHECK.b21ea2c.zh-CN.md)。

| --- | --- | --- |
| 描述被正确加载 | 必需字段、版本、资源边界和歧义的正反例经过真实 loader 检查；前后端差异明确 | 已有校验源码及回归源码，尚未重跑。不同格式不能互换。 |
| 字段操作遵守描述 | 独立检查实际 wire 的可变、固定、派生字段；不能仅由编码器自验 | 全字段检查和最终 framing 检查已接入支持范围；待执行验证。 |
| 完整序列约束 | 实际 M1、新 M2、保留 M3 共用消息数、重复数、字节数及模型状态检查 | 生产模式检查链已修改；旧有意破坏仅允许匹配本次候选，并用有效投影检查上下文；generic-wire 不支持该模式。 |

| 方法有效性 | 相同目标、种子、配置及预算下，对原策略与新策略作重复对照，报告实际执行量及波动 | 本轮未开展对照，未建立收益结论。单元通过、构建成功、状态数增加均不能替代。 |

`structured_runs` 在宿主准备调用目标执行时递增，不能单凭此计数证明子进程启动或处理完成。`complete_transmissions` 必须按全部计划消息完整提交解释；响应观察是否完整是独立条件，进入有效反馈和队列还需响应资格。零字节 send 尝试是诊断事件，不是 replay 中的零长度消息。部分提交记录用于诊断，不作为完整候选证据。

`stats_version:2` 的 `completed_responses` 表示预期 pending 响应完成，`correlated_responses` 仅在至少一条适用字段相等规则实际检查且全部通过时增加。无 `stats_version` 的旧统计采用版本1口径，不能推断字段验证发生过。未知版本不推测解释。

默认确认要求实际提交 wire 精确相等；不自动忽略 session/token 等字段。确需等价规则时应另行定义可审查契约并验证，不能为使确认通过而静默归一化。tracer ABI v3 的显式边界提供者须为单进程、单线程，在每个完整应用消息处理完成后按序发布；多 producer 冲突拒绝观察，旧 ABI 须重新构建。

磁盘文件摘要只能说明观察到的文件内容，不能认证运行进程映像或构建来源。冷启动恢复会重置学习状态，新 segment 不是不中断的调度器检查点。
