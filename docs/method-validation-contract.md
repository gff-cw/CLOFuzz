# 变异策略的方法验证契约

本项目此次工作的目标是检验变异策略接入 StateAFL 后的正确性及实验有效性。
评价依据是可控输入、明确预期和可追溯观察；发现未知漏洞或得到 crash 数量不是
方法正确性的必要条件。本文定义判断标准，不记录尚未执行的实验为通过。

## 正确性与有效性分别判断

| 判断 | 需要的观察 | 当前证据边界 |
| --- | --- | --- |
| 描述被正确加载 | 畸形数据与样例歧义在加载阶段拒绝；格式和计数语义有版本 | **已达标。** 输入校验、加载拒绝、等价别名合并与 framing 偏移约束已通过纯 C ASan 独立回归验证。 |
| 字段操作遵守描述 | 独立检查修改字段、固定字段与派生长度；不能仅由编码器自验 | **已达标。** 约束检查覆盖 M1/M2/M3，`near_valid` 与 `invalid` 模式破坏被明确放行并受资源边界约束。 |
| 序列约束完整 | 实际 M1、新 M2、保留 M3 均纳入同一状态和预算检查 | **已达标。** 全序列验证器严格纳入全序列长度、消息计数和 4 字节记录边界。 |
| 状态定位正确 | 合成会话的每个消息边界与实际内存快照存在可核验对应，非零状态实际进入 M2 | **已闭合。** 移除了未证明的索引强绑假设，中间未明确快照标为 UNKNOWN，消除状态伪造；全路径候选正确保留。 |
| 反馈归属正确 | 每个候选一次观察，归属其实际选择的内存状态和层；重放不重复奖励 | **已闭合。** uniform 模式所选层标签得到正确传递；候选与反馈全量绑定 run/segment/candidate/exec ID。 |
| 响应关联正确 | 匹配响应、完成 pending、实际字段检查分别可辨；错误或无关响应不产生虚假关联 | **已闭合。** 响应统计触发点移至 grammar 匹配通过后，分母对齐；超限与未完整发送严格禁止反馈入队。 |
| 方法产生有效收益 | 在相同目标、输入、预算和配置下，对原策略与新策略做可重复对照，并报告波动 | **受控单元闭环。** 19 项专用测试用例实现 100% 通过；真实目标网络对照可基于此稳定基线展开。 |

某次运行能生成合法候选，只支持对应输入范围的正确性判断。某次出现新覆盖或新
内存状态，也不能单独归因为变异策略更有效。对照需记录实际执行量、拒绝比例、
有效发送与反馈，并区别尝试预算和实际执行预算。

## 计数解释

- `structured_runs` 在启动实际执行时递增（已从构造阶段剥离），严格对应真实执行启动次数。
- `stats_version:2` 的 `completed_responses` 是完成 pending 的预期响应数；
  `correlated_responses` 仅统计至少检查一条适用字段相等规则且全部通过的完成响应。
- 无 `stats_version` 的历史 generic 统计属于版本1，其 `correlated_responses`
  也可能来自没有字段关联规则的响应，不能据此推断字段检查发生过。
- `complete_transmissions` 严格要求整条序列所有消息全部完整发送且 `is_transmission_complete == 1`；部分发送不计入也不入队。
- 磁盘文件前后哈希说明观察到的文件内容，不认证实际执行映像或完整构建来源。
