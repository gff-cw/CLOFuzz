# 变异策略的方法验证契约

本项目此次工作的目标是检验变异策略接入 StateAFL 后的正确性及实验有效性。
评价依据是可控输入、明确预期和可追溯观察；发现未知漏洞或得到 crash 数量不是
方法正确性的必要条件。本文定义判断标准，不记录尚未执行的实验为通过。

## 正确性与有效性分别判断

| 判断 | 需要的观察 | 当前证据边界 |
| --- | --- | --- |
| 描述被正确加载 | 畸形数据与样例歧义在加载阶段拒绝；格式和计数语义有版本 | 输入校验和加载拒绝已有源码修正，新增回归尚未执行。 |
| 字段操作遵守描述 | 独立检查修改字段、固定字段与派生长度；不能仅由编码器自验 | 历史虚构协议验收覆盖有限报文；未证明复杂工业语义。 |
| 序列约束完整 | 实际 M1、新 M2、保留 M3 均纳入同一状态和预算检查 | 当前 M3 尚未纳入，不能宣称完整会话正确。 |
| 状态定位正确 | 合成会话的每个消息边界与实际内存快照存在可核验对应，非零状态实际进入 M2 | 当前共享序列缺少可靠边界元数据，非零状态入口仍有阻断。 |
| 反馈归属正确 | 每个候选一次观察，归属其实际选择的内存状态和层；重放不重复奖励 | 历史在线观察只有 state ID 0，人工注入 ID 的 harness 不能替代实际定位。 |
| 响应关联正确 | 匹配响应、完成 pending、实际字段检查分别可辨；错误或无关响应不产生虚假关联 | 新 generic 统计版本2区分完成与字段关联；源码待执行验证。 |
| 方法产生有效收益 | 在相同目标、输入、预算和配置下，对原策略与新策略做可重复对照，并报告波动 | 当前通用引擎没有可据以宣称普遍收益的对照证据。 |

某次运行能生成合法候选，只支持对应输入范围的正确性判断。某次出现新覆盖或新
内存状态，也不能单独归因为变异策略更有效。对照需记录实际执行量、拒绝比例、
有效发送与反馈，并区别尝试预算和实际执行预算。

## 计数解释

- `structured_success` 是候选构造成功数，不能直接解释为成功发送数。
- `stats_version:2` 的 `completed_responses` 是完成 pending 的预期响应数；
  `correlated_responses` 仅统计至少检查一条适用字段相等规则且全部通过的完成响应。
- 无 `stats_version` 的历史 generic 统计属于版本1，其 `correlated_responses`
  也可能来自没有字段关联规则的响应，不能据此推断字段检查发生过。
- memory discovery 不等于之后选中了该非零状态；当前 memory discovery 又受
  覆盖率保留门槛限制，两种新颖性并非独立观察通道。
- 磁盘文件前后哈希说明观察到的文件内容，不认证实际执行映像或完整构建来源。
