| 未解决项 | 源码依据与结论 |

| 描述与执行范围 | [静态元数据](../tools/proto_spec_compiler.py#L33)、[CONTENT契约](../tools/proto_spec_compiler.py#L698) 和[模式处理](../protocol_runtime.c#L615) 显示部分条件不执行、near_valid/invalid共用有限违例操作 |

[BACnet记录](bacnet-adaptive-results.md) 支持短预算下的有限联动和状态0学习，不证明非零状态学习或六协议普遍收益。[历史在线验证](online-directed-integration.md) 不能代替上述缺口的专项验证。
